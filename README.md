# P2P Communication App (Node + Relay)

Цей репозиторій містить вихідний код і скрипти збірки для прототипу децентралізованої P2P-системи комунікації (вузол-клієнт та relay-вузол).

> Примітка: пояснювальна записка/дипломна робота до цього проєкту **не** публікується в цьому репозиторії.

## Склад

- `src/` — вихідний код C++ (клієнт/вузол, relay та допоміжні модулі)
- `third_party/` — сторонні залежності (включно з `jech/dht`)
- `build_relay.sh`, `build_linux.sh`, `build_win.sh`, `setup_win_sysroot.sh` — скрипти збірки
- `pkg_extra/` — додаткові файли для пакування
- Зібрані артефакти (приклади в `build/` у локальній збірці): `p2pnode`, `p2pnode.exe`, `p2p-relay`

## Збірка (Linux)

```bash
cd app
./build_linux.sh
```

Очікуваний результат: бінарник вузла (наприклад, `build/p2pnode`).

## Збірка relay (Linux)

```bash
cd app
./build_relay.sh
```

Очікуваний результат: `build/p2p-relay`.

## Збірка для Windows (крос-компіляція з Linux)

```bash
cd app
./setup_win_sysroot.sh   # за потреби
./build_win.sh
```

Очікуваний результат: `build/p2pnode.exe`.

## Використання (загально)

Після збірки запускайте зібрані виконувані файли відповідно до параметрів вашої конфігурації/мережі (див. вихідний код у `src/` та внутрішні опції запуску). Конкретні аргументи командного рядка залежать від реалізації в `src/main.cpp` та `src/relay_main.cpp`.
